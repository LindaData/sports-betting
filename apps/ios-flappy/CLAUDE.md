# PitchFlap (loaded when files under apps/ios-flappy/ are read)

A one-tap arcade game for iPhone: a football through goalposts. SwiftUI shell, SpriteKit scene, iOS 17+, portrait, no assets, no dependencies. Built and run only on the owner's Mac; cloud sessions cannot compile Swift.

- **Charter and gates:** `STUDIO.md`. **How the code works:** `LEARN.md`. **Conventions (binding):** `.claude/rules/ios-flappy.md`.
- **Every feel constant:** `PitchFlap/Tuning.swift`. **Every colour:** `PitchFlap/Palette.swift`. **The game:** `PitchFlap/GameScene.swift`.
- **Run a sprint:** `/studio <goal>`. The agents are `studio-producer`, `studio-designer`, `studio-engineer`, `studio-reviewer`, `studio-release`, `studio-analyst`, `studio-art`.
- **Evidence for every decision:** `studio/research/01`–`04`.

Two things never happen here: the word "Flappy" in anything user-facing, and a claim that Swift was verified when it was not compiled.
