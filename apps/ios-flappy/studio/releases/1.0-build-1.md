## Owner: one-time Mac and account setup

1. Xcode 26+ installed and selected: `sudo xcode-select -s /Applications/Xcode.app`; open Xcode once to accept the license. — https://developer.apple.com/news/upcoming-requirements/
2. **Xcode → Settings → Accounts**: add your Apple ID so the development certificate lands in this user's keychain.
3. Open `PitchFlap.xcodeproj`, select the PitchFlap target → Signing & Capabilities → tick automatic signing, choose your Team, and build to your phone once (⌘R). This proves the hand-written project compiles and seeds the keychain. **Do not commit the team ID that Xcode writes into the pbxproj**; the hook will stop you if you try. `git checkout -- PitchFlap.xcodeproj` afterwards.
4. App Store Connect: bundle ID `com.lindadata.pitchflap` registered; app record created (name ≤ 30 characters, SKU, primary language). — https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app
5. App Store Connect API key with **App Manager** role (Users and Access → Integrations). Download the `.p8` once. — https://developer.apple.com/documentation/appstoreconnectapi/creating-api-keys-for-app-store-connect-api
6. Repository secrets: `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_PRIVATE_KEY` (`base64 -i AuthKey_XXXX.p8 | pbcopy`), `APPLE_TEAM_ID`.
7. Self-hosted runner registered from **Settings → Actions → Runners → New self-hosted runner → macOS**; installed as a service with `./svc.sh install && ./svc.sh start`; Mac set not to sleep on power.

## First upload

- Trigger **Actions → iOS TestFlight → Run workflow** on `claude/pitchflap-studio-agents` (or ask this session to trigger it). Watch the Archive step; the first run on a fresh keychain can prompt for keychain access on the Mac once — click "Always Allow".
- App Store Connect → TestFlight: the build appears as "Processing" for 5–15 minutes, then is available to **Internal Testing**. Add yourself to an internal group; you get the TestFlight push on your phone. No review for internal groups. — https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview
- Export compliance: with the key above the build should show no "Missing Compliance" banner. If it does, answer "No" to the encryption question once in App Store Connect and note it here.
